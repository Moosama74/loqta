# منصة لُقطـة للسيارات (Loqta Cars Egypt) 🚗💰
> الموقع المصري المتخصص في صفقات السيارات، بيع وشراء وتأجير السيارات، مع نظام متكامل لتحصيل العمولات والأرباح.

---

## 🌟 فكرة ومميزات المنصة

تم بناء منصة **"لُقطـة"** لتكون بديلاً عصرياً وسريعاً لمنصات مثل (هتلاقي، دوبيزل / أوليكس)، مع التركيز الأساسي على **تحقيق الأرباح والعمولات** لصاحب المشروع من خلال 4 قنوات ربحية أساسية:

1. **عمولات حجز الإيجار الفوري:**
   * حجز أي سيارة إيجار يومي أو سياحي يتم بسداد **عربون حجز إلكتروني أونلاين** (يمثل عمولة المنصة مباشرة)، ويسدد باقي المبلغ لمكتب التأجير عند استلام السيارة.
2. **باقات ترقية الإعلانات المميزة (VIP & Loqta Featured):**
   * إعلان مجاني أساسي للمستخدمين.
   * باقة **"إعلان مميز لقطة" (199 ج.م)** لتثبيت الإعلان لمدة 14 يوماً بأول نتائج البحث.
   * باقة **"سوبر VIP" (399 ج.م)** لتثبيت الإعلان شهراً كاملاً مع شارة ذهبية وإشعارات للمشترين.
3. **خدمة فحص لقطة المعتمد (100 نقطة فحص):**
   * خدمة حجز فحص فني شامل للشاسيه والدهان والموتور والفتيس في مراكز فحص شريكة، برسم **1,500 ج.م** لكل فحص.
4. **عمولات تقسيط وتأمين السيارات (Affiliate Leads):**
   * حاسبة تقسيط فورية مدمجة بالسيارات، تتيح للزائر تقديم طلب تمويل بنكي، وتحصل المنصة على عمولة إحالة من البنك أو شركة التمويل (من 2,500 إلى 4,500 ج.م لكل موافقة).
5. **لوحة تحكم الأرباح الشاملة (`/admin`):**
   * شاشة خاصة لصاحب الموقع ترصد لحظة بلحظة: إجمالي أرباح المنصة، عمولات الإيجار، رسوم الباقات المميزة، وحجوزات الفحص.

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **Backend & API:** Python FastAPI (فائق السرعة وخفيف جداً)
* **Database:** SQLite مع SQLAlchemy ORM (جاهزة للترقية لـ PostgreSQL بنقرة واحدة)
* **Frontend:** Tailwind CSS + Alpine.js + Jinja2 Templates (تصميم عربي كامل RTL متوافق مع الموبايل والديسكتوب)
* **Icons & Fonts:** FontAwesome 6 + Google Cairo Font

## 🚀 طريقة التشغيل السريعة

1. اضغط مرتين على ملف **`run.bat`**
2. أو من خلال الطرفية (Terminal / PowerShell):
```powershell
cd "C:\Users\SHOEIB TEK\.gemini\antigravity\scratch\loqta-cars"
python -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```
3. افتح المتصفح على:
* الموقع الرئيسي: **http://localhost:8000**
* سوق السيارات والبحث: **http://localhost:8000/cars**
* أسطول الإيجار والعمولات: **http://localhost:8000/rentals**
* لوحة تحكم الأرباح والعمولات: **http://localhost:8000/admin**
